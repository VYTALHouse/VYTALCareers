# Roadmap

## Phase 0 — control

- Confirm repository boundary and owners.
- Link enterprise canon and decision log.
- Classify every existing file and media asset.

## Phase 1 — foundation

- Define schemas, interfaces and validation tests.
- Build the first deployable surface or reusable package.
- Add CI checks without secrets.

## Phase 2 — integration

- Connect approved interfaces to the applicable VYTAL repositories.
- Add test fixtures containing no live PII or PHI.
- Document rollback, ownership and approval gates.

## Phase 3 — controlled release

- Complete security, legal, compliance, brand and claims review as applicable.
- Promote only approved media and copy.
- Record release status and successor links.

Current priority: Define phased hiring plans without publishing applicant data, compensation promises or unapproved opening dates.
